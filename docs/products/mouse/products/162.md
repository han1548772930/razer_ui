# 当前独立入口 162：Cobra／DeviceInfo 163

当前官方保留的 `/products/162/ui/` 有独立 HTML、manifest 与 JS，部署稳定性已经获取收据核验。当前产品登记表不列 162，不能仅凭这一点把仍可取得的入口当作无效源码。

这份入口实际导出的 `DEVICE_NAME` 为 Razer Cobra，`DeviceInfo.productId` 为 163，类别 MOUSE、VID 5426；可用 edition 数组是 `[0]`。入口路径编号与设备身份在当前字节中并不相同，不把二者强行归一，也不据此新增一种 162 硬件。UI manifest 为 1.0.1／build 2；同一获取闭包保留的 MW manifest 为 1.0.0／build 3，各自身份独立核对。

DeviceInfo 的原始范围为 `[1656117,1656751)`，位于下面链接的主 JS，所属完整模块 `[1634186,1660886)`。这份表给定 DPI 200–8500、步长 100、不支持独立 XY；OBM 标为 true、槽数 4，硬件配置切换存在，OBM 支持 brightness／DPI、不支持 pollingRate；不能把这些字段覆盖到登记入口 163 的另一版本而省略比较。

此独立入口的导航为 Customize → Performance → Lighting → Calibration → Help。下面保存其实际组件，而非复制 163 的组件区间。

源码入口与字节身份见 [获取收据](../../../../.analysis/inputs/frontend/mouse-162-current/acquisition.json)。本文件按实际源码数组保留页面顺序；同名页面处于不同数组时分别记录。声明分块不等于当前正在显示，条件表达式决定实际使用分支。

阅读功能目的、输入含义和读写链请同时查看 [本产品族功能说明](../README.md) 和 [源码阅读约定](../../shared/source-reading.md)。
