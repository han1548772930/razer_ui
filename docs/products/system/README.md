## 影响行为的跨型号差异

709、710、711、736、737 在主机端运行智能风扇曲线，拥有独立温度监控、追赶计时器、插值和停止链。其余系统使用各产品定义的模式／固定转速控制；完整模式和 RPM 表见性能文档，不能把通用构造器的某一组转速当作全族范围。

独立 Battery 从 650／651／652 开始挂载；独立 Display 从 669／670／671／672 开始挂载。更早产品的显示卡片可能嵌在 Performance，缺少独立标签不代表没有显示功能。Sound 只在 694、695、696、709、710、711、736、737 挂载；后一组五个产品声明 thxv4，736／737 另观察独立本地音频客户端。

Hyperboost 的静态支持、固件／SKU、接电状态、低功率适配器与真实就绪配件分别检查。711 声明 VC 灯；737 明确关闭 VC 灯，即使其默认配置保留相应字段。所有 41 个实际系统键盘 render 均挂载 Snap Tap；硬件 OBM 支持则必须沿各产品 feature 判断，不能由 UI 挂载推定。
