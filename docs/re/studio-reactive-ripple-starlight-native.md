# Studio Reactive / Ripple / Starlight 属性接入（2026-10-07）

本批把三个原先未挂载的属性根接为实际控件。来源仅为当前 `.ref/applications/synapse/chroma-studio/` 的 manifest 声明文件；分别从父 `4264:se` 的懒加载条件进入 `7518`、`5305`、`6548`，没有执行厂商 JavaScript。

[独立源码收据](studio-reactive-ripple-starlight-current-evidence.json)以每个效果各自的 Source 实例重新读取当前模块，避免另一个懒加载页覆盖同编号共享模块后被当作本页来源。包括 62 项 AST、4 个 CSS 文件中的 218 条相关规则、8 张原始 SVG 的当前源/本地哈希，以及逐控件条件、范围和剩余边界。完整效果验收仍为 **0**。

## 数字输入和生命周期

数字与范围由 `chroma_studio_numeric.rs` 的三个独立实体持有，实际参数仍归 `StudioProperties`。`2245` 的键盘过滤与 HTML number 文法分开处理：步长不小于 1 时阻止点号、加减号和小写 e 键，但粘贴以及大写 E 仍可能形成有效数值。原码 onInput 只改局部 n，未回写 target.value，不能据此把所有输入提前改成整数。

因此本地编辑值使用有限 f64：`1e1` 为 10，`1.5` 编辑时保持 1.5、Blur 后为 2；宽度 `1.5e2` 编辑时为 150、Blur 后为 200。空值/HTML number 无效文本对应 Number("") 的 0；Blur/Enter/Escape 才按 `7660:x5` 先夹至 min/max、再 `Math.round(value/step)*step`。这些是静态回读向量，未运行浏览器或 Rust 测试验证。

按钮短按在释放或离开时步进；300ms 后进入长按，首个重复步在再过 100ms 后发生，与原版定时器顺序相同。按钮到达边界禁用；窗口级释放清理覆盖按钮变禁用或移出后的情况。按键 Up/Down 和数字步进使用同一网格规则。按住状态在失活、Reset、图层或工具变化后取消；代际检查拒绝旧数字事件写入新参数。

程序同步先设置预期字段，再更新被观察的 slider；observer 对比归一化值，避免把输入中的 150 因为滑条显示 200 而立即回写成 200。Change/Release 可能都通知，但相同 params 不再次改变父状态。输入和范围各有名称与键盘路径，仍待真实窗口/辅助功能客户端验收。

## 设备、保存与剩余差异

`4264:se` 的条件是没有真实选中设备且使用 Select/Move 时禁用。当前本地画布没有接入真实选中设备，故这些工具仍禁用；Pen/Bucket 允许编辑工作参数，不用目录或默认产品填造已选设备。未知设备状态、混合字段 `paramsMixed`、实际能力过滤和读取发布者尚未接通。

本批编辑只修改已有本地工作参数，Pen↔Bucket 保留；涉及 Select/Move 的切换按原有源码默认值规则恢复/合并，图层切换替换，Reset 合并当前画笔默认值。它们不是图层文档、已应用 LED 区域或设备保存成功。既有本地图层保存仍独立；`9286:U` 应用到真实设备区域的腿未接，DLL 修改/保存继续后置。
