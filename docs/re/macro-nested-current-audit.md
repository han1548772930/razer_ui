# 当前 Macro 嵌套宏选择：2026-10-05

本专项继续共享文档库集成，接入此前不可用的嵌套宏选择、持久引用与候选循环检查。当前源 AST/CSS 和 Rust 指纹并入 [Macro/快捷键机器收据](shortcuts-macro-current-contract.json)，通过维护工具 `audit-shortcuts-macro-contract.cjs` 生成。这里只解析当前 manifest 对应的厂商文本，没有执行它。

## 源码事实

当前 Macro `8190.61506f5b.chunk.js / 58190.En` 对宏列表建立 GUID 图，从每个宏的 `macroEvents` 中读取 Type 7 的 `guid`。候选能递归到当前宏时标为 disabled。`je` 再排除当前宏自身，按 GUID 寻找当前选项；引用目标不存在时显示 `37927.Adr = TEXT_SELECT_A_MACRO`，不改绑第一项。

`je` 将筛选后的选项转换回原始 macroList 索引，派发 `4173.Lt = updateMacroItem`。业务 reducer `Zs` 为改变创建撤销快照，`25572.C`（导出 NH）在 `case d.W1` 写 `MPIndex` 和 `guid = macroList[index].guid`。显示名来自目标文档，重命名不改变身份。

候选保持 macroList 创建顺序，不跟随 profile tree 的名称排序和移动。只有一个候选时仍允许展开；只有候选为空才禁用下拉。禁用候选由 `97278` 渲染为没有选择回调的 inactive 行。

宏复制 `25572.iV` 只为复制文档生成新 GUID，嵌套事件中的目标 GUID 保持原值；没有把文件夹内引用自动改成对应副本。

## 本地接入

`ActionItem` 新增可选 `macro_id`，是共享本地库的单调 ID，不是原生 GUID。旧六字段动作通过默认值加载，未分配 ID 的旧行保持未分配，不能凭名称猜测身份。`value` 可保留选择时的显示名快照，实际显示与选择均只根据 `macro_id` 查找目标。

新增 `macro_page/nested.rs`：

- 候选排除当前宏，并按本地 ID 恢复创建顺序；空宏仍可选。
- 从当前动作、暂存的非当前草稿和已保存文档取得实际活动图；候选存在返回当前宏的路径时禁止选择。
- 每次绘制和选择时重新检查路径，避免原 `useMemo([currentGuid, macroList.length])` 在仅动作变化时保留过期结果。
- 路径遍历使用 visited 集合，在文件里已有循环时也能终止。此适配不把原递归无界行为带入 UI，也不声称已验证原生引擎可执行这些文件。
- 更换引用创建一次撤销快照，清除重做，显式保存才进入已保存文档；复制沿用源行为保留原目标 ID。删除目标后显示源 placeholder，身份不重用。
- 读取/写入拒绝零 ID、超出高水位的引用、非 Macro 动作上的引用和指向文件夹的引用。已删除且低于高水位的目标可保留；不将其误报为数据丢失而拒绝整个工作区。

源候选检查基于活动草稿，不是每份已保存快照的组合。本地也保留这一区别：不同文档只保存部分修改时，已保存图可能不同于当前活动图。本地不执行宏，持久化没有声称已经完成全库可执行性验证。

## 样式和边界
