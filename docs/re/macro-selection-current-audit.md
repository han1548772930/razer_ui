# Macro 选择与工具栏续接（2026-10-05）

依据当前 Macro 58190 的 `br/va/ha/ke/be`、25572.M 和 main 业务 reducer 的五个选择/删除分支。`tools/audit-macro-selection.cjs` 用 Acorn 解析组件、reducer、实际 CSS，并记录本地代码和八个原始资源的哈希；不运行下载的 JavaScript。

本轮将无行为的工具栏方框接为全选/取消全选。逐行选择全部动作后，顶部同步选中；部分选择不会冒充全选。选择只影响编辑器会话，不写入保存动作或制造一次撤销记录。录制设置打开或首次引导未完成时不接受选择和删除操作。

选中计数和批量删除恢复到 actionbar 左侧，替换时长显示；删除不再出现在本地额外的 40px 底栏。使用当前 `icon_delete` / `icon_delete_r` 两份 SVG 和源码 20px/5px 间距。撤销、重做按是否可用选择 default/enable/hover 三份原始资源，按下透明度 0.7。真实录制仍不可用，未伪造录制状态。

事件行恢复 #111 背景、42px 高度、10px 左右 padding、透明边框/底部 #222 和悬停绿色描边。旧 `rgb(0x44d62c33)` 把含 alpha 的值当作 RGB，现改为 `rgba`。有可信本地 pair_id 和 state 的键盘动作按 25572.M 高亮对应行；高亮不会自动选中对方，也不会扩大批量删除范围。鼠标和 Loop 缺少这种配对数据，未以相同文本猜测配对。

checkbox 恢复 20px、2.4px 圆角、#737373 边框、绿色选中状态和 40px 总槽宽（label 的 margin-right 10px 加外层 mr10）。未选中行仅悬停时显现，opacity 200ms。勾线使用按左上原点旋转的 3px 宽圆角矩形；短线 100ms，长线按 `ticktop` 的 50% 零高度关键帧先等待 100ms、后绘制 100ms。减少动画遵循现有 motion 设置。

仍未完整实现：源 200ms leading/trailing 选择防抖、鼠标/Loop 配对、配对连接线、每行复制/删除、成组拖动及配对拖动边界、工具栏专属 tooltip、完整 Phased 编辑器、原生录制/设备服务。既有单行拖动的插入方向还需按当前 reducer 修正，不能将此次选择修复算作完整拖拽验收。

本轮只做静态解析、资源校验、格式化和统一 `cargo check --locked --all-targets`，没有运行应用、构建或测试，也没有实际画面与输入验收结论。
