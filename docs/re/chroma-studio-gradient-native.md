# Studio Spectrum 渐变编辑器：2026-10-06

当前来源为 `.ref/applications/synapse/chroma-studio/` 的 manifest 声明文件。`8552:b` 挂载颜色区域，`3690:b/N` 定义渐变编辑与选择器，`99` 定义触发框，`1592` 定义弹层生命周期，`9170/9220/3968` 定义颜色转换、百分比 stop 和渐变显示。完整模块、文件 SHA-256、UTF-16 范围和 CSS 收据见 [属性源码收据](chroma-studio-properties-source.json)。提取器只解析源码，不执行厂商 JavaScript。

## 已接入范围

- Spectrum 的 COLOR 标题、帮助和渐变触发框；弹层宽 230px、内边距 10px，渐变条宽 180px、高 16px，内嵌调色区宽 208px。
- 五组当前源码预设，独立自定义渐变缓存；预设的 25×16px 尺寸、间距、白色选择环、100ms 边框和按下遮罩过渡。
- 色标选择、添加、删除、拖动；至少保留 2 个，最多 10 个。点击采样位置取原始 180px 画布像素中心，位置四舍五入到两位小数。拖动按相邻 stop 限制，间隔为 `ceil(6/(180-6)*100)/100`。显示位置保留源码避免色标重叠的 7px 顺移规则。
- 色标颜色、透明/无色、亮度、HEX/RGB、固定与自定义颜色。共享调色器新增 dropdown 尺寸，保留 Static 原本的 228px 画布；颜色画布按源 CSS 裁剪。
- 连续编辑只更新渐变草稿和自定义缓存；松开、输入提交、预设和增删才发布 `{colorStops, colorStopsCustom}`，位置按整数百分比序列化，无色省略 Color 字段。
- 弹层先挂载零高度，100ms 后显示；关闭立即变为零高度，100ms 后卸载。窗口失活保留弹层并清理拖动；重新打开选择首个色标。宿主重建时保留自定义渐变缓存。

`StudioProperties` 持有编辑器，接收提交后只修改 `effectLayer.params` 对应的本地工作参数。没有写入图层文档、设备区域或 DLL。缓存不冒充已保存用户配置。色标使用稳定内部 ID；键盘方向键、Home/End 和删除复用相同边界，属于原生可访问性补充。

## 尚未验收与剩余差异

- 原生取色仍无可用服务，保持禁用。设备选择混合值和真实设备预览尚未接入。
- GPUI 0.7 的 CursorStyle 只有内置枚举，没有原图自定义光标；源码 select-add SVG 光标尚未接入，当前使用系统默认光标。
- 弹层由 Base Popover 处理焦点、Escape、外部点击和避让；其窗口边缘避让与原始非 portal CSS 弹层不同，尚需进一步对齐。触发框的边框已使用源颜色，但其 100ms 颜色过渡仍待补齐。
- 渐变以 sRGB 预乘 alpha 插值显示和取样。浏览器 Canvas2D 的像素量化、DPI 下的缩放与 GPUI 输出尚未运行对比，不能声称像素一致。
- 共享调色器仍保留此前记录的 HEX 显示大小写差异，见 [颜色编辑器](chroma-studio-color-native.md)。
