# 本地设备配置范围

产品必须在没有账户、没有互联网连接时使用。本地服务与设备配置架构参考 [OpenLogi](https://github.com/AprilNEA/OpenLogi)。

| 必须完整实现 | 从产品 UI 与 dispatch 移除 |
| --- | --- |
| 本地设备发现、直连通信、查询、状态观察、变更和设备／服务写回 | 账户、登录、云身份 |
| 本地配置文件、映射、宏、灯光、音频和摄像头设置 | 云同步、云存储、远程预设目录 |
| 本地预设、持久化、后台服务、系统集成和本地 IPC | 在线内容、在线商店、远程下载 |
| 错误、确认、取消、资源清理、安装与本地生命周期 | 远程更新编排及其他依赖互联网服务的功能 |
| 本地文件固件传输、本地 DLL 替换／写回 | 对以上联网功能的禁用占位或伪造成功反馈 |

本机 IPC、loopback 和与已安装本地服务通信的 socket 属于本地功能。需要按实际调用链分类，不能只看名称或 URL：Cloud EQ 的本地预设保存、DSP／HID 写入和本地还原仍需实现；远程目录获取和云同步需要移除。

完整复现意味着完整实现每个本地交互及其设备／服务效果。当前 JS/CSS 和资源决定布局、文案、控件、状态、挂载条件及确认／失败语义。每个动作需追踪参数、调用方、transport／服务、响应、刷新、取消、持久化和清理。保留原始乐观更新；没有原始调用链依据时，不能新增弹窗、回滚或 getter 覆盖 UI 的行为。Rust 附加诊断与原始 UI 状态分开。

本地草稿保存与设备写入成功分别记录；缺失本地能力明确显示缺失。未实现操作、模拟 transport 成功和本地持久化不能伪装成真实设备读写。

原生分析以安装的 IDA Pro／Hex-Rays 为主，静态分析私有副本，保存原始字节身份、RVA、函数边界、完整伪代码／汇编和交叉引用。当前前端源直接静态解析。OpenLogi 仅用于架构设计，不能作为 Razer wire protocol 证据。

允许格式化、静态解析、资源准备／校验、`cargo check --locked --all-targets`、纯 Rust 单元测试和模拟 transport 测试。禁止运行应用、独立构建验收、厂商 JavaScript、目标 DLL、helper、installer、真实服务操作或真实设备操作。允许下载用于静态分析的官方源码／二进制证据。
