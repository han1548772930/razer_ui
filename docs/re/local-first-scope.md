# 本地设备配置范围

产品的本地设备功能必须在没有账户、没有互联网连接时使用。用户授权的静态界面资源交付是例外：所有实际打开的界面，包括设置、宏、帮助、独立窗口及产品页，按需获取所用文件和共享依赖；缓存命中不联网，未打开的页面或产品不全量预取。固定系统按钮图标随程序内嵌。

全部本地功能须按当前官方源码和二进制逆向后由本项目独立实现。官方 DLL 仅用于静态分析和显式对照测试，不是生产后端；动态加载、链接、FFI 包装、IPC 转发或回退调用均不能代替 Rust 实现。先修正架构，完整实现协议、状态、事件、读写、持久化和清理，再删除对应加载器、CommonDll 等实现定位规则及生产依赖。现存 DLL 调用属于待完成的替代工作，不能仅清理名称或删去功能后宣称完成。具体边界以 [根目录规则](../../AGENTS.md) 为准。

| 必须完整实现 | 从产品 UI 与 dispatch 移除 |
| --- | --- |
| 本地设备发现、直连通信、查询、状态观察、变更和设备／服务写回 | 账户、登录、云身份 |
| 本地配置文件、映射、宏、灯光、音频和摄像头设置 | 云同步、云存储、远程预设目录 |
| 本地预设、持久化、后台服务、系统集成和本地 IPC | 在线内容、在线商店、远程下载 |
| 错误、确认、取消、资源清理、安装与本地生命周期 | 远程更新编排及其他依赖互联网服务的功能 |
| 本地文件固件传输、本地 DLL 替换／写回 | 对以上联网功能的禁用占位或伪造成功反馈 |

本机 IPC、loopback 和与已安装本地服务通信的 socket 属于本地功能。需要按实际调用链分类，不能只看名称或 URL：Cloud EQ 的本地预设保存、DSP／HID 写入和本地还原仍需实现；远程目录获取和云同步需要移除。

“本地配置”不等于只维护一份本地文件。设备读取、状态观察、修改、设备／服务写回、真实确认、刷新、持久化、取消和清理都必须完整实现。连接、重连和打开页面按当前源码执行读取与初始化，实际结果进入对应页面与控件，不能任意把本地旧值或默认值写回覆盖设备。

设备当前状态、用户待提交草稿和持久化配置分别建模。未读取、读取中、失败、断开、未知协议值和已确认值明确区分，禁止读取失败后回退本地配置或默认值。未返回的字段保持未观测，不能从档位数量或缓存推断开关。草稿可以保留，但不能冒充设备状态；文件保存不等于设备成功，设备应答也不能冒充未执行的读回。

首次使用且当前源码／协议证明确需初始化时，保留有依据的默认值，并完成真实初始化、必要写入与确认；用户明确恢复默认也走对应实际设备链。首次被本程序发现、缺少本机配置文件、读取失败或断开，都不证明设备没有配置，不能据此覆盖设备已有值。

默认值内容、初始化条件、读取／写入顺序、结果消费者及失败语义全部依据当前官方源码。源码规定的必要初始化／恢复写入不能遗漏，也不能为了状态区分自行增加通用初始化、回退、回滚、弹窗或另一套配置页面。

完整复现意味着完整实现每个本地交互及其设备／服务效果。当前 JS/CSS 和资源决定布局、文案、控件、状态、挂载条件及确认／失败语义。每个动作需追踪参数、调用方、transport／服务、响应、刷新、取消、持久化和清理。保留有依据的乐观编辑；真实 getter 通过已核实的协议进入页面，不能因原版读取配置缓存而丢弃实测结果。不得杜撰协议字段、弹窗或回滚；Rust 附加诊断、设备实测和用户草稿分开。

本地草稿保存与设备写入成功分别记录；缺失本地能力明确显示缺失。未实现操作、模拟 transport 成功和本地持久化不能伪装成真实设备读写。

原生分析以安装的 IDA Pro／Hex-Rays 为主，静态分析私有副本，保存原始字节身份、RVA、函数边界、完整伪代码／汇编和交叉引用。当前前端源直接静态解析。外部工程只用于架构设计，不能作为 Razer wire protocol 证据。

允许格式化、静态解析、资源准备／校验、`cargo check --locked --all-targets`、纯 Rust 单元测试和模拟 transport 测试，也允许下载官方源码／二进制证据。用户已授权通过已核实的本地 DLL 测试本地服务／设备功能：先只读对比，可恢复写入须记录原值、恢复并读回确认。来源、版本、架构、ABI 与清理必须核实，实际结果单独记录，加载 DLL 不代表功能一致。应用窗口、独立构建验收、厂商 JavaScript、未授权 helper／installer 和调试器执行仍不运行。
