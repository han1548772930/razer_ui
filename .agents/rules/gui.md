# GUI、共享组件与词表

- 修改前阅读两套 GPUI 技能及适用机制文档，按 `Cargo.lock` 确认签名。共享依赖变化时核对 GPUI／Kit 的包身份和版本，不能顺手混用另一套 API 或重复 GUI 栈。
- shell 组合功能；页面拥有交互和页面状态；设备 I/O、持久化与资源 I/O 由各自服务负责。render 只读状态、查内存资源和组合元素，不能启动会话、读写磁盘或等待网络。
- 控件行为使用语义组件，外观由当前 Razer JS／CSS、产品主题与比例入口决定。公共组件问题修到组件所有者，同时核对全部产品调用方、弹窗、独立窗口、tooltip 和共享导航。
- Overlay、延迟绘制和窗口根是独立的上下文边界。资源缓存、焦点、输入与任务归属按锁定框架的实际机制传递，不能假定外层上下文自动跨边界保留。复用 `razer-assets` 的资源作用域和延迟绘制入口。
- 资源选择与请求状态分开；alias、产品／版本条件、原始顺序及动态资源分支由统一目录和维护输入校验。资源未请求、加载中、失败、已缓存与解码失败不能混为成功空图，也不能预取未打开页面作为补救。
- 稳定选择身份不能使用文案或列表位置。过滤、语言切换和重新加载后保留正确选择；输入、焦点、滚动、任务和订阅由长期存在的 entity 持有，避免在 render 中重建。
- 静态词表由随程序安装的 SQLite 目录库提供；修改消息时核对各语言键、插值参数、产品条件与顺序。使用稳定语义键，不从显示文案派生身份，不另建 TOML／JSON 生产词表副本。
- 语言或主题切换时更新实际持有的缓存文案、菜单、占位文本与窗口状态，避免实体更新中重入。只在当前原件支持的语言与状态范围内复现行为，缺少翻译依据不能杜撰一致性。
- 检查原版键盘路径、焦点转移／恢复、关闭与取消行为及所有交互状态。静态组件检查和纯逻辑测试不等于窗口、像素或真实设备验收；后者受根目录执行限制约束。
